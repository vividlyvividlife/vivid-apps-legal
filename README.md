# vivid-apps-legal

Публичный сайт только с политиками конфиденциальности Android-приложений VIVID-ШКОЛА.
Здесь нет сайта школы, игр и аналитики — только юридические документы.

## Адреса

- `/` — хаб документов приложений.
- `/speed-reading/` — политика приложения «Чтение на скорость».

Публичный адрес: `https://vividlyvividlife.github.io/vivid-apps-legal/`.

## Добавить приложение

1. Создать папку `<slug>/index.html` с политикой по образцу `speed-reading/index.html`.
2. Добавить карточку приложения в `index.html`.
3. Указать этот URL в карточке RuStore и в `privacyUrl` соответствующего Android-приложения.
4. Пересобрать APK/AAB приложения.

## Публикация

В GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Сборка не нужна: сайт состоит из статических HTML и CSS.

Не добавлять сюда счётчики, внешние шрифты и скрипты.
